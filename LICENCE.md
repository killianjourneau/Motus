## Ce qui est protégé

**Le code source** — pages, feuilles de style, scripts, schéma de base de
données. Œuvre originale au sens du code de la propriété intellectuelle.

**Les contenus rédigés** — les quelque 2 500 notices de personnages, de prénoms

textes de l'interface. Chacun est une œuvre de l'esprit.
