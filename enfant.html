Comment jouer

  • Il faut trouver un mot caché. La première lettre est donnée.
  • Pour écrire une lettre, touche l'image qui commence par cette lettre : le 🦁 Lion écrit un L.
  • Une case rouge : la lettre est à la bonne place.
  • Un rond jaune : la lettre est dans le mot, mais ailleurs.
  • Une case grise : la lettre n'est pas dans le mot.
